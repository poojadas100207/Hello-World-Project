# Core Concepts Practice

A study repository for core programming topics. Each directory contains a focused example, a small exercise, and notes that explain the approach.

## Topics

- `data-structures/`: stack implementation and usage
- `algorithms/`: binary search with complexity notes
- `programming-fundamentals/`: functions, validation, and control flow
- `web-basics/`: accessible HTML, CSS, and browser JavaScript
- `self-assessment/`: command-line knowledge checks

## Run the JavaScript examples

```bash
node data-structures/stack.js
node algorithms/binary-search.js
node programming-fundamentals/temperature.js
node self-assessment/quiz.js
```

## Learning goals

By the end of this repository, a learner should be able to explain data representation, choose an algorithm based on complexity, write small testable functions, and connect HTML structure with browser behavior.
